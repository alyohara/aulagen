Operación y despliegue

El procesamiento de materiales y las generaciones pueden ejecutarse en segundo plano. Asegurá colas, almacenamiento y servicios de datos persistentes.

Comandos frecuentes

# Estado y logs de los servicios Docker
docker compose ps
docker compose logs -f app

# Comandos Laravel dentro del contenedor
docker compose exec app php artisan migrate --force
docker compose exec app php artisan tinker

# Detener servicios sin eliminar volúmenes
docker compose down

Colas y almacenamiento

Docker inicia Horizon en el servicio queue. En un entorno local, ejecutá php artisan horizon o un worker apropiado antes de procesar archivos o solicitar contenido generado.

Los archivos cargados usan el sistema de almacenamiento de Laravel. En producción usá un disco persistente, realizá copias de seguridad y ejecutá php artisan storage:link cuando los archivos públicos se sirvan desde el disco local.

Lista de preparación para producción

  1. Definí APP_ENV=production, APP_DEBUG=false y un APP_KEY único y seguro.
  2. Usá credenciales seguras para PostgreSQL, Redis y el proveedor de IA.
  3. Configurá un APP_URL HTTPS correcto y un proxy o servidor web que termine TLS.
  4. Persistí y respaldá la base de datos y el almacenamiento de la aplicación.
  5. Ejecutá Horizon o un worker bajo un supervisor confiable.
  6. Revisá el tratamiento de datos del proveedor de IA y eliminá las cuentas de demostración.
GitHub Pages no hospeda AulaGen: la página de documentación es estática. La aplicación necesita PHP, una base de datos, Redis, workers y almacenamiento persistente.

Diagnóstico

SituaciónQué verificar
Un material queda pendiente o fallaTipo y tamaño del archivo, worker/Horizon, estado del documento y mensaje de error.
Falla una generación de IAProveedor seleccionado, prueba de conexión, clave, URL, modelo, límite de tasa y worker.
El asistente no respondeQue existan materiales procesados, que el asistente esté habilitado y que haya fragmentos pertinentes.
El estudiante no ve contenidoQue la materia esté publicada y que las lecciones correspondientes estén aprobadas o publicadas.
Docker no conecta a la baseEsperá el health check de db y revisá docker compose logs db app.

Recuperación local

# Limpiar configuración y cachés luego de cambiar .env
php artisan optimize:clear

# Reiniciar datos de desarrollo
php artisan migrate:fresh --seed

# Validar frontend y pruebas de aplicación
npm run build
vendor\bin\phpunit
