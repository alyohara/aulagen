Arquitectura

AulaGen es una aplicación Laravel con una interfaz React servida mediante Inertia. Combina procesamiento de documentos, colas y un proveedor de IA configurable.

Componentes

CapaTecnología / función
AplicaciónPHP 8.2+, Laravel 12, Laravel Horizon y Sanctum.
InterfazInertia.js, React 18, TypeScript, Vite y Tailwind CSS.
Datos de producciónPostgreSQL 17 con pgvector y Redis.
Desarrollo localSQLite como base por defecto; Docker Compose para el stack completo.
IAGestor de proveedores, embeddings, búsqueda vectorial y recuperación aumentada por generación.

Flujo de material a aula

  1. Carga. Un docente incorpora archivos o recursos externos en una materia.
  2. Procesamiento. Un job extrae texto, conserva metadatos y divide el material en fragmentos.
  3. Indexación. Cuando el proveedor lo admite, se crean embeddings para recuperar fragmentos relacionados con una consulta.
  4. Autoría asistida. La IA puede generar propuestas de estructura, contenido, actividades y glosario desde las fuentes disponibles.
  5. Revisión. El docente ajusta y aprueba contenido; la publicación controla qué es visible para estudiantes.
  6. Consulta. La búsqueda y el asistente recuperan fragmentos de la materia para devolver resultados contextualizados.

Rutas principales

ÁreaPropósito
/dashboard y /courses/{course}Panel docente y gestión de materias.
/adminUsuarios, generaciones y configuración global de IA.
/aula/{course}Aula publicada, módulos, lecciones, actividades, bibliografía, glosario y recursos.

Seguridad de publicación

Las áreas de gestión requieren autenticación, verificación de cuenta y las capacidades correspondientes. La capa pública filtra las lecciones según la publicación y el estado de cada lección. El diseño separa el trabajo en borrador de la experiencia disponible para estudiantes.

Despliegue de documentación

El workflow de GitHub Actions publica el contenido de docs/ en GitHub Pages cuando hay cambios en esta carpeta o en el propio workflow. No compila ni ejecuta el backend: el sitio de documentación usa HTML y CSS estáticos.
