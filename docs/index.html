Documentación

Creá aulas virtuales a partir de tus materiales.

AulaGen permite transformar fuentes docentes en cursos navegables, con asistencia de IA y una revisión humana antes de publicar.

Importante: este sitio documenta el proyecto. GitHub Pages solo sirve estas páginas estáticas; la aplicación Laravel debe desplegarse en una infraestructura propia.

Elegí tu recorrido

Instalar AulaGen

Iniciá el entorno completo con Docker o prepará un entorno local con PHP, Node.js y SQLite.

Crear un aula

Subí materiales, generá una propuesta, revisá el contenido y publicá para tus estudiantes.

Administrar IA y usuarios

Configurá proveedores, roles, límites y los criterios de privacidad de tu institución.

Operar y desplegar

Consultá colas, almacenamiento, recomendaciones de producción y soluciones frecuentes.

Cómo funciona

  1. Incorporá fuentes. Agregá documentos y recursos a una materia.
  2. Construí el contenido. AulaGen procesa las fuentes y puede proponer estructura, lecciones, actividades y glosario.
  3. Revisá cada decisión. Editá, aprobá o descartá el material antes de que sea visible.
  4. Publicá el aula. Los estudiantes acceden a las lecciones y herramientas habilitadas para esa materia.
