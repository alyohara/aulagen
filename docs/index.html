Open-source AI-assisted learning platform

Your teaching materials, shaped into a virtual classroom.

AulaGen helps educators turn their own course files into structured lessons, activities, and a student-facing classroom—while keeping every publication decision in the teacher's hands.

Explore the repository See how it works

AI organizes. Educators decide.

The platform is designed around human review, not automatic publishing. AI accelerates course preparation while teachers remain responsible for the final learning experience.

01Bring your materialUpload documents and add links or video references to a course.
02Index the knowledgeText is extracted, chunked, embedded, and made searchable.
03Build the classroomAI proposes modules, lessons, activities, and a glossary from those sources.
04Review and publishEdit, approve, reject, and publish exactly what students should see.

One platform, two focused experiences.

AulaGen supports the people who create a course and the people who learn from it.

For educators

Create courses, upload and assign material, organize modules and lessons, generate learning content, and control publication.

For students

Follow a clear lesson path, record learning progress, complete self-check activities, browse sources, and search course content.

For administrators

Manage users, roles, AI settings, provider connectivity, and generation activity from a dedicated administration area.

Answers grounded in the course material.

The student assistant uses retrieval-augmented generation (RAG): it retrieves relevant pieces of the course's indexed content, supplies them as context, and returns source references. Teachers can disable the assistant or control whether external knowledge is allowed.

Teacher-owned context
  • Content chunks created from uploaded resources
  • Semantic vector search with lexical fallback
  • Source labels carried into generated responses
Provider flexibility
  • Local Ollama models for self-hosted workflows
  • Google Gemini and OpenAI support
  • OpenAI-compatible custom endpoints and local fallback

Built for a practical, self-hosted stack.

The web application combines Laravel 12 and Inertia React with a Docker Compose development environment.

Application

PHP, Laravel, Inertia.js, React, TypeScript, Vite, and Tailwind CSS.

Data and jobs

PostgreSQL with pgvector, Redis, queued processing, and Laravel Horizon.

Local development

Docker Compose for the complete stack, with SQLite available for a lightweight local setup.
