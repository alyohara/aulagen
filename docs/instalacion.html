Instalación

Docker Compose es la opción recomendada: levanta la aplicación, las colas, PostgreSQL con pgvector y Redis.

Requisitos

OpciónNecesitás
Docker (recomendada)Docker Desktop 20.10+, Docker Compose v2, Git y los puertos 8000, 5432 y 6379 libres.
Desarrollo localPHP 8.2+, Composer, Node.js 22+, npm y SQLite. Para una configuración similar a producción se requieren PostgreSQL y Redis.

Con Docker Compose

  1. Cloná el repositorio y prepará el archivo de entorno.
git clone https://github.com/alyohara/aulagen.git
cd aulagen
cp .env.example .env
  1. Construí e iniciá los servicios.
docker compose up -d --build

Abrí http://localhost:8000. El contenedor ejecuta las migraciones cuando RUN_MIGRATIONS=true. Si hace falta crear la clave de aplicación, ejecutá:

docker compose exec app php artisan key:generate

IA local con Ollama

Ollama es opcional. Para iniciar su servicio y descargar los modelos configurados:

docker compose --profile ollama up -d
docker compose exec ollama ollama pull llama3.2
docker compose exec ollama ollama pull nomic-embed-text

Desarrollo local en Windows

git clone https://github.com/alyohara/aulagen.git
Set-Location aulagen
composer install
npm install
Copy-Item .env.example .env
php artisan key:generate
New-Item -ItemType File -Force database\database.sqlite
php artisan migrate --seed
npm run build
php artisan serve --host=127.0.0.1 --port=8000

Al procesar materiales, iniciá las colas en otra terminal:

php artisan horizon

También podés usar composer run dev para iniciar el servidor, el worker, los logs y Vite juntos.
